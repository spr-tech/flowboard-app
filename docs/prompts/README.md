# Prompts for Claude Code

Paste one prompt per milestone, in order, on that milestone's branch (for example `git switch -c rebuild/m1-foundation rebuild`). Don't paste the next one until the current milestone meets its "done when" in `docs/plan/06-build-order.md` and you've merged its PR into `rebuild`.

Before milestone 1, copy your own `frontendStructureGuide.md` into `docs/`.
